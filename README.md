# Frontier 1905

An interactive map of the ideas that led to Einstein's special relativity (30 June 1905).

The circle is the edge of human knowledge in 1905, with time running outward from the centre. Each dot is an idea, placed by field and date. Click any idea to see what it was built on and what it led to. Special relativity sits on the swell in the rim, where synthesis across fields pushed the frontier outward. The hatched shapes beyond the rim are ideas that came after.

Open `index.html` in a browser. Everything (code, data and thumbnails) is in that one file; fonts load from Google Fonts.
